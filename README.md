# Java Gold SE 17 対策サイト（章構成更新版）

## 起動方法
このフォルダで以下を実行してください。

```bash
python3 -m http.server 8000
```

ブラウザで以下を開きます。

```text
http://localhost:8000
```

スマホで確認する場合は、PCとスマホを同じWi-Fiに接続し、PCのIPアドレスを使って以下のように開きます。

```text
http://<PCのIPアドレス>:8000
```
