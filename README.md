# Java Gold SE 17 JSON連携プロトタイプ（基礎問題入り）

## 内容
- `index.html`: Java Gold風CSS + JSON読込対応HTML
- `questions.json`: Java Gold SE 17向けの基礎問題 60問

## 起動方法
このフォルダで以下を実行してください。

```bash
python3 -m http.server 8000
```

ブラウザで以下を開きます。

```text
http://localhost:8000
```
